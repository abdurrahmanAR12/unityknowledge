# Package Guides

These pages go deeper than the broad system overviews.

Use them when you know **which package** you care about, and you want:
- setup guidance
- common problems
- best practices
- adoption warnings
- what to avoid in production

## Suggested reading order

### For most Unity developers
1. Input System
2. Addressables
3. Cinemachine
4. Timeline

### For specialization
- AR Foundation
- Netcode for GameObjects
- XR Interaction Toolkit and OpenXR
- DOTS / Jobs / Burst / Entities

## Rule for packages

A package should enter your project because it solves a specific problem,
not because it looks impressive in the Package Manager.
