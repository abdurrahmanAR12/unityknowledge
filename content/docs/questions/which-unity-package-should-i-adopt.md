# Which Unity Package Should I Adopt?

Use this rule:

Adopt a package only when:
- you can name the problem it solves
- the team can support it
- it is compatible with your editor/platform goals
- the maintenance cost is worth it

Good defaults:
- Input System for modern input
- Addressables for non-trivial content loading
- Cinemachine for camera workflows
- Timeline for sequence authoring

Specialization packages:
- AR Foundation for AR
- Netcode for GameObjects for multiplayer on GameObject projects
- XRI/OpenXR for XR interaction/runtime workflows
- DOTS/Jobs/Burst only when measured needs justify them
